# Skills

Official uCoz Agent Skills are **not** vendored in this repository.

Install and browse them here:

https://github.com/ucoz-skills/agent-skills

That repository also ships IDE plugins (Cursor, Codex, Claude, Antigravity). Connect remote MCP from this repo (`https://www.ucoz.com/mcp`), then install skills from `agent-skills`.

## Available skills

| Skill | What it does |
|-------|--------------|
| [ucoz-landing-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-landing-skill) | Homepage landing pages |
| [ucoz-ad-campaign-landing-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-ad-campaign-landing-skill) | Per-segment ad landings with UTM and ad drafts |
| [ucoz-shop-optimizer-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-shop-optimizer-skill) | Online Shop audit and improvements |
| [ucoz-site-translator-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-site-translator-skill) | Content translation and localization |
| [ucoz-design-editor-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-design-editor-skill) | Redesign and restyling of an existing site |
| [ucoz-template-creator-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-template-creator-skill) | Original site-wide templates |
| [ucoz-server-scripts-skill](https://github.com/ucoz-skills/agent-skills/tree/main/skills/ucoz-server-scripts-skill) | Backend features in Server Scripts (`apps_tool`): PHP, Node.js, Python, MySQL, cron |

Versions and install commands: [agent-skills README](https://github.com/ucoz-skills/agent-skills#available-skills).
